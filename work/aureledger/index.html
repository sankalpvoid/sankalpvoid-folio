Does it count as spending?

The ledger follows accounting rules rather than the order mail arrives. Make a call on each, then see what it does. Amounts are illustrative.

  • A card purchase₹1,200 at a restaurant, on the credit card

    Counts, on the day it happens. Cash only moves when the bill is paid, so the overview shows card spending hatched, as real spending whose bill is still to come.

  • Paying the card bill₹12,000 from the bank account

    Doesn’t count. It settles purchases already counted. Counting it again would double the expense, so it is shown as a card bill paid.

  • Moving money between your own accounts₹20,000, savings to current

    Doesn’t count. Own-account transfers, investments and income are not consumption.

  • A reminder that a SIP is due in two days₹5,000 instalment

    Not yet. A scheduled SIP is a commitment, and it counts only once money has moved. The reminder, the bank debit and the allocation stay linked but each keeps its own amount, so 5,000 and 4,999.75 are shown as they are, not smoothed.

Three decisions.

Fixed parsers, not an LLM.

The alert formats are known and fixed, so each one has a deterministic parser. Nothing is sent to an AI provider and results are reproducible. A message that doesn’t match is marked unreadable and put in front of you for review. Nothing is guessed.

Say what’s missing.

The ledger is only as complete as the mail it received, so the import start date and per-source coverage are shown. A portfolio value needs a real holding and an exact fund mapping, and otherwise reads “Unavailable” with the reason. Credit score is “not connected”.

Verify the sender before reading.

Messages are read only from allow-listed senders with a passing authentication result. A forged “dkim=pass” header placed below Gmail’s own failing one is rejected, and this is covered by tests. Message bodies are discarded after parsing and only redacted text of recognised alerts is kept.

Status

Where it stands. Concept, design and build. The public intro and a synthetic demo are live; the private workspace sits behind Google sign-in with per-user row-level security on Postgres. At the last verification report the automated suite had 71 tests, and a deployed-app concurrency run had checked isolation between users with no cross-user rows.

Not verified. Gmail sync has only run against a simulated Gmail API. No real mailbox has been imported yet, so parsing of real bank, card and SIP alerts is untested. Safari, Firefox and phones were not tested. The source is private and every figure on this page is synthetic.
